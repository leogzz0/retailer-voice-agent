# Crédito para tiendas — Productos Nopalia

> Contenido ficticio para un proyecto de práctica.

## Condiciones generales
- El plazo de pago es de **15 días naturales** a partir de la fecha de entrega.
- Cada tienda tiene un **límite de crédito** asignado. Un pedido nuevo no puede rebasar el
  crédito disponible.
- El crédito disponible se libera cuando se registra el pago.

## Formas de pago
- Efectivo al repartidor (se entrega recibo).
- Transferencia o depósito a la cuenta de Nopalia, indicando el número de cliente como referencia.

## Pagos atrasados
- Con **más de 15 días de atraso** se suspenden pedidos nuevos a crédito hasta regularizar la cuenta.
- No se cobran intereses durante el piloto de 2026.

## Aumentos de crédito y aclaraciones
- Los aumentos de límite, aclaraciones de saldo y facturas los atiende **el área de crédito**.
  Vera no puede modificar el crédito: debe pasar la llamada con un asesor.
- Vera sí puede decir el **crédito disponible** después de verificar la identidad de quien llama.
